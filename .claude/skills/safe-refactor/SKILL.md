# 안전 교정 — 동작 보존이 전제

승인된 교정만 적용한다. 핵심은 속도가 아니라 **동작 보존** — 안전망이 교정마다 통과/실패를 확실히 갈라준다. 깨지면 그 자리에서 되돌린다.

## 왜 이렇게 하는가

리팩토링은 코드를 옮길 뿐 동작을 바꾸지 않는 작업이다. 여러 교정을 한꺼번에 묶으면 회귀가 났을 때 어느 변경이 원인인지 못 잡는다. 그래서 한 건씩, 매번 안전망을 통과시키며 간다. 안전망이 없는 채로 변경하면 "동작 무변경"을 증명할 방법이 없다 — 그건 리팩토링이 아니라 도박이다.

## 안전망 (가드)

| 가드 | 무엇을 덮나 | 명령 |
|------|------------|------|
| **렌더 골든 지문** | 캔버스 그리기(나무·바닥·장식·카메라) 그리기 호출 시퀀스 동일 | `npm test` 의 렌더 지문 일치. 기준값은 `test/render-smoke.test.js` 의 `GOLDEN` 상수(현재 값은 `grep -n GOLDEN test/render-smoke.test.js` 로 확인) |
| **단위 테스트** | 순수함수·경계 계약(seed·activation·metrics·aggregate·bundle-rule 등) | `npm test`(node --test) 전 케이스 |
| **구문/적재** | 문법·import 바인딩 | `node --check`, 동적 `import()` 로 모듈 적재 확인 |
| **브라우저 스모크** | 자동 시험이 없는 영역(main·state·ui·debug·묶은 숲·오버뷰 스냅샷·카메라 이동) | `?debug` 모드로 띄워 콘솔 에러 0 + 기능 동작(claude-in-chrome 스크린샷이 결정적 증거) |

## 작업 원칙

- **한 번에 하나**: 한 교정 = 한 변경 → 가드 통과 확인 → 다음. 묶지 않는다.
- **동작 불변**: 본문 로직·숫자·문자열은 한 글자도 안 바꾼다(주석·import·이름·위치만). 의도적 동작 변경이면 리팩토링이 아니라 별도 작업으로 분리.
- **안전망 우선**: 교정 대상을 덮는 가드가 없으면 **가드부터 신설**한다 — 그 경로를 골든 픽스처에 추가해 기준값을 다시 잡는다. 가드 없이는 변경하지 않고 "가드 신설 필요"로 보류·통지.
- **고아 정리**: 내 변경이 만든 미사용(import·함수·죽은 호출)만 제거. 기존 죽은 코드는 보고만(요청 없이 삭제 금지).
- **과교정 거부**: reviewer 가 "두는 게 맞음"으로 판정한 강결합(오버뷰 스냅샷·카메라 양방향 등)은 건드리지 않는다.

## 골든 지문 — 갱신이 금지인 경우 vs 정답인 경우

지문은 그리기 호출 로그의 해시다. 리팩토링 중 지문이 깨지면 **동작이 바뀐 것**이다.

- **우회 갱신 금지**: "코드 안 바꿨으니 괜찮겠지"라며 기준값을 그냥 새로 잡으면 안전망이 무너진다. 깨진 원인을 찾아 본문/호출부를 원래대로 고친다. 못 맞추면 그 교정 되돌리고 "동작 변경 위험"으로 보류.
- **의도된 변경엔 갱신이 정답**: 골든 픽스처를 확장했거나(빈 땅 칸 추가 등) 아트를 바꾼 경우처럼 동작 변경 자체가 목적이면 기준값 갱신이 옳다. 단, 리팩토링 회차에는 원칙적으로 발생하지 않는다.
- **캐시·배치 최적화의 지문 자연 감소**: 베이크·메모이제이션으로 호출 횟수가 줄어 지문이 바뀌면, 캐시 우회 결과와 픽셀(색·좌표·순서) 동일을 별도 증명한 뒤에만 갱신을 정당화한다.

## god-file 분리 순서

수천 줄 파일은 위험 성격 단계별로 끊어, 매번 검증 그물을 통과시키며 뗀다. 한 회차에 다 쳐내면 회귀 위치를 못 잡는다.

| 단계 | 대상 | 검증 그물 |
|------|------|-----------|
| 1 | 순수 데이터/상수(의존 0) | 적재 + 구문 검사 |
| 2 | 순수 함수(`this` 미참조, 형제만 호출) | 단위 테스트 + 적재 |
| 3 | 인스턴스 상태 보유(`this.cache` 등) | 골든 지문 + 통합 |
| 4 | 외부 입력·DOM·타이머 | 실모드 픽셀·이벤트(브라우저 스모크) |

`this.` 가 줄줄이 묶인 함수를 억지로 자유 함수로 빼면 인자에 상태가 따라온다(§2 위반) — 협력 객체로 빼거나 그 자리에 둔다.
